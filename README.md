# 💰 My Wallet

My Wallet is a modern, responsive personal finance tracker built with **React**, **Redux Toolkit**, **Vite**, and **Tailwind CSS**.  
You can add income/expense transactions, see your current balance, and manage your recent financial history with ease.

---

## 🚀 Live Demo

[🔗 View it on GitHub Pages](https://iamali-stack.github.io/My-Wallet)

---

## 🧩 Features

- 📊 Add income and expense transactions
- 🧮 Automatically calculated current balance
- 🧾 View and delete recent transactions
- 🧠 Soft delete (UI-only deletion) without affecting the balance
- 📱 Responsive and mobile-friendly design
- 🔥 Built with modern stack: React + Redux Toolkit + Tailwind CSS + Vite
